# ClipForge AI

ClipForge turns an authorized long-form video into editable, subtitle-ready short clips. The application runs locally with Next.js, FastAPI, PostgreSQL, Redis, Celery and FFmpeg.

## Start with Docker

Prerequisites are Docker Engine with the Compose plugin and sufficient storage for source files, previews, and exports. A CPU-only worker is suitable for local use.

1. Copy `.env.example` to `.env`. Set `APP_SECRET` and `POSTGRES_PASSWORD` to **two different** values generated by `openssl rand -hex 32`.
2. Configure the AI providers below. You can sign in and upload with providers disabled. Processing pauses with a retryable error at the first unconfigured stage.
3. Run `docker compose up --build -d`. On installations with the standalone binary, use `docker-compose`.
4. Open [the dashboard](http://localhost:3000). Register an account or provision an administrator with `docker compose exec api python -m app.admin you@example.com`. The command prompts for a password. Set `ALLOW_REGISTRATION=0` before running a private instance.
5. Open [API documentation](http://localhost:8000/docs) for request schemas, or use `docker compose logs -f api worker` for service logs.

The API applies versioned Alembic migrations before accepting traffic. PostgreSQL, the Redis broker, and media storage each have their own volume.

## AI providers

| Variable | Purpose |
| --- | --- |
| `STT_PROVIDER` | `remote` with an OpenAI-compatible transcription service, or `local` with faster-whisper |
| `STT_API_KEY`, `STT_BASE_URL`, `STT_MODEL` | Remote transcription. Default `whisper-1` requests word and segment timestamps |
| `LOCAL_WHISPER`, `WHISPER_MODEL` | Set `LOCAL_WHISPER=1` before building the Docker image. Local Whisper defaults to `small` and downloads weights on first use |
| `LLM_PROVIDER`, `LLM_API_KEY`, `LLM_BASE_URL`, `LLM_MODEL` | OpenAI-compatible chat completions with JSON mode. Defaults to `remote` |
| `SCORE_WEIGHTS` | Weights for hook strength, clarity, emotional impact, and standalone value |
| `FACE_TRACKING`, `ENABLE_FACE_TRACKING` | Set both to `1` and rebuild to enable optional OpenCV face detection |

Remote keys stay server-side. Providing a remote service allows that service to receive audio for transcription or transcript text for discovery. Restart the API and worker after changing provider settings. English, Hindi, and Nepali are selectable where the transcription model supports them. Accuracy varies by speech, language and model. Transcript edits can supply corrected segment timing and text.

For a fully local native setup, start a compatible server on loopback, for example:

```sh
llama-server -hf Qwen/Qwen2.5-3B-Instruct-GGUF:Q4_K_M \
  --host 127.0.0.1 --port 8085 --alias clipforge-local -c 8192 --cors-origins http://localhost:3000 --no-cors-credentials
```

Use `STT_PROVIDER=local`, `LLM_PROVIDER=local`, `LLM_BASE_URL=http://127.0.0.1:8085/v1` and `LLM_MODEL=clipforge-local`. The explicit local LLM mode accepts a loopback URL and requires no API key. Loopback inside Docker refers to that container. Native launch is the documented option for this loopback configuration. [faster-whisper](https://github.com/SYSTRAN/faster-whisper) · [llama.cpp server](https://github.com/ggml-org/llama.cpp/tree/master/tools/server) · [Qwen GGUF weights](https://huggingface.co/Qwen/Qwen2.5-3B-Instruct-GGUF)

## Try a sample

Generate a short narrated clip with FFmpeg and macOS `say` or Linux `espeak-ng`.

```sh
./scripts/generate-sample.sh
```

In the dashboard, choose **New Project**, upload `storage/samples/clipforge-sample.mp4`, confirm authorization, and select **Start processing**. Choose an AI suggestion and open **Edit clip**. Adjust the in and out points, output shape and captions as needed. New clips use High quality, match the source frame rate, and shorten long pauses where the audio confirms silence between spoken words. Captions are retimed around those cuts. Smart framing preserves the full shot when a stable single-face crop is unavailable. After rendering, select **Last export** for playback, **Download MP4** for the clip, or **SRT** for the caption file.

The project view exposes transcript and retry controls. If analysis finishes with no usable candidates, adjust the duration ranges, save the discovery settings, and retry. Direct URL ingestion accepts HTTPS links to video files, including signed object-storage URLs that respond directly with HTTP 200. Set `MEDIA_URL_HOSTS` for an exact allowlist, or set `ALLOW_PUBLIC_MEDIA_URLS=1` on a trusted local deployment. An allowlist takes precedence when both are set. Use an authorized file upload for restricted platform footage.

## Native development

Install Python 3.12, Node 24, FFmpeg with libass and libx264, Redis, PostgreSQL, and fonts for the languages you intend to caption. On macOS the `ffmpeg-full` Homebrew formula provides libass. Put its `bin` directory first on `PATH`.

```sh
python3.12 -m venv .venv
.venv/bin/pip install -r backend/requirements.txt
npm --prefix frontend ci
```

Create a PostgreSQL database and set `DATABASE_URL` to its SQLAlchemy `postgresql+psycopg://` URL. Set `REDIS_URL` to the running Redis instance and `MEDIA_ROOT` to a private absolute directory. The API, worker and beat process need the same environment and media root. When using local Whisper, install `faster-whisper` in the venv. SQLite is available for development and tests. Use PostgreSQL for concurrent jobs.

From separate terminals, load trusted environment values and start the API, worker, scheduler, and frontend.

```sh
cd backend
../.venv/bin/alembic upgrade head
../.venv/bin/uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

```sh
cd backend
../.venv/bin/celery -A app.worker.queue worker --loglevel=INFO --concurrency=1
```

Use `--pool=solo` for native macOS local Whisper if forked workers encounter runtime problems.

```sh
cd backend
../.venv/bin/celery -A app.worker.queue beat --loglevel=INFO --schedule /tmp/clipforge-beat
```

```sh
npm --prefix frontend run dev
```

Use `localhost` for the browser URLs so the app and API share the same cookie site.

## Verification

```sh
.venv/bin/pip install pytest
(cd backend && ../.venv/bin/python -m pytest -q)
npm --prefix frontend run build
.venv/bin/python scripts/smoke.py storage/samples/clipforge-sample.mp4
```

The automated test suite substitutes the two AI providers and checks real FFmpeg output, visible burned captions, a ranged download, access isolation, retry behavior, and validation. The final command calls real configured providers and downloads a vertical MP4 and an SRT file. Pass an authorized direct HTTPS video URL instead of a local path to test URL ingestion. It creates a test account and a project on the running instance.

## Deployment

See [deployment notes](docs/deployment.md) for TLS, quotas, S3 and operational limits. The dashboard exposes internal usage and job activity. Editorial scores help rank clips and represent judgment about each excerpt. They do not use audience data.

The publishing page provides a manual export-and-upload workflow. OAuth connections, approvals and scheduling against platform APIs are a later milestone. Smart framing optionally makes one stable crop around a consistently detected face. Speaker diarization, active speaker switching, split screen, external analytics and real-time styled previews are outside this implementation. The rendered preview reflects all visual settings.
